# pastlives-wiki

MediaWiki for [Past Lives Makerspace](https://pastlives.space), deployed on Render at [wiki.pastlives.space](https://wiki.pastlives.space).

## What this repo is

A thin custom Docker image that extends the official `mediawiki:1.41` image and adds the PostgreSQL PHP driver (`php-pgsql`), which the upstream image does not ship. Everything else — the wiki application, themes, install wizard — comes from upstream.

The Render service `pastlives-wiki` (`srv-d7mgjubbc2fs7387t8f0`) builds and deploys from this repo on every push to `main`.

## Architecture

| Piece | Where |
|---|---|
| **Web service** | Render — `pastlives-wiki` |
| **Database** | Render Postgres (`mediawiki` DB on the shared `plfog` instance) |
| **File uploads** | Cloudflare R2 (`plfog` bucket, `mediawiki/` prefix) via the `AWS` MediaWiki extension |
| **Domain** | `wiki.pastlives.space` |
| **DB / R2 secrets** | Render env vars (`MW_DB_*`) — never commit them |

## Files

- **`Dockerfile`** — extends `mediawiki:1.41`, installs `pdo_pgsql` and `pgsql` PHP extensions.
- **`LocalSettings.php`** — gitignored until first generated by the installer. After install:
  1. Download `LocalSettings.php` from `/mw-config/` at the end of the wizard.
  2. Replace any literal secrets with `$_ENV` reads, e.g.:
     ```php
     $wgDBpassword = $_ENV['MW_DB_PASS'];
     ```
  3. Commit. From then on, configuration changes are made via PR, not via SSH.

## Local development

```sh
docker build -t pastlives-wiki .
docker run --rm -p 8080:80 pastlives-wiki
```

Then open `http://localhost:8080`.

## Deploying

Push to `main`. Render auto-deploys.

## Secrets / env vars on Render

Set on the `pastlives-wiki` service:

| Var | Value |
|---|---|
| `MW_DB_TYPE` | `postgres` |
| `MW_DB_SERVER` | Render Postgres host |
| `MW_DB_NAME` | `mediawiki` |
| `MW_DB_USER` | `mediawiki_user` |
| `MW_DB_PASS` | (from `.env.prod` `MEDIAWIKI_DB_PASSWORD` in the plfog repo) |
